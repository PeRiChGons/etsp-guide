# Aplicaciones Android e iOS

La aplicación utiliza la guía pública como contenido y no muestra la interfaz de GitHub.

- Android: se genera con Capacitor/Android Studio.
- iOS: se genera con Capacitor/Xcode en macOS.
- Unity no es necesario.
- El acceso, los perfiles y el chat pertenecen a Supabase.
- Antes de publicar en tiendas se sustituirá `server.url` por una copia local completa en `www` para asegurar funcionamiento sin conexión.
